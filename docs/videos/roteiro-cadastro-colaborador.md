# 🎬 Roteiro — Cadastro de Colaborador

**Vídeo:** `cadastro-colaborador.webm` · **Duração:** ~30s · **Tela:** Gestão de Colaboradores

> Roteiro de narração pronto para gravar (voz humana ou TTS). Os tempos são aproximados e seguem as legendas do vídeo.

| # | Cena (legenda no vídeo) | Narração sugerida |
|---|---|---|
| 0 | *Cadastro de Colaborador — Passo a passo* | "Vamos cadastrar um novo colaborador no Aurora, passo a passo." |
| 1 | *Clique em Adicionar* | "Na tela de Gestão de Colaboradores, clique no botão **Adicionar**." |
| 2 | *Escolha Cadastro Manual* | "Escolha **Cadastro Manual** para preencher os dados na tela. (Também é possível **Importar Planilha** para vários de uma vez.)" |

| 4 | *Informe o CPF* | "Digite o **CPF** — o sistema valida o número automaticamente." |
| 5 | *Informe o E-mail* | "Informe o **e-mail** corporativo, usado nas avaliações." |
| 6 | *Data de Nascimento* | "Preencha a **data de nascimento**." |
| 7 | *Selecione o Departamento* | "Selecione o **departamento** na lista." |

## Dicas para a versão final
- **Voz:** gravar narração humana ou gerar por TTS (ex.: ElevenLabs/Azure) e sincronizar com as legendas.
- **Conversão:** o vídeo está em `.webm`; para `.mp4` use `ffmpeg -i cadastro-colaborador.webm cadastro-colaborador.mp4`.
- **Campos obrigatórios:** Nome, CPF, E-mail, Data de Nascimento, Departamento e Cargo. Telefone é opcional.

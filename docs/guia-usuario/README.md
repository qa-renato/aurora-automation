# 📘 Guia do Usuário — Aurora

Bem-vindo(a) ao Aurora, a plataforma de acompanhamento de bem-estar e saúde ocupacional. Este guia explica, **rotina por rotina**, como usar cada tela.

## Acesso
O Aurora é acessado pelo navegador. O login é feito com sua **conta corporativa (Microsoft / inbot)** — clique em entrar e autentique com seu usuário da empresa. O que você vê depende do seu **perfil de acesso**.

## Índice por rotina
1. [Home / Painel](home.md) — visão geral dos indicadores
2. [Gestão de Colaboradores](colaboradores.md) — cadastro e gestão de pessoas
3. [Pedidos de Protocolo](pedidos.md) — solicitar questionários
4. [Adesão e Engajamento](adesao.md) — acompanhar respostas
5. [Métricas da IA](metricas-ia.md) — uso do assistente
6. [Casos Graves](casos-graves.md) — gestão de tratativas
7. [Relatórios Individuais](relatorios-individuais.md) — BAI, BHS, BDI, BSS
8. [Relatório COPSOQ](relatorio-copsoq.md) — entrevista ocupacional
9. [Resultados Consolidados](resultados-consolidados.md) — visão geral
10. [Auditoria](auditoria.md) — histórico de ações
11. [Configurações](configuracoes.md) — ajustes da plataforma

> Dica: a navegação entre as rotinas é feita pelo **menu lateral**. Use o botão de menu para recolher/expandir.

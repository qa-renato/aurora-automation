# Adesão e Engajamento

Tela para **acompanhar quem já respondeu** os questionários de um lote.

## O que você vê
- **Seletor de Lote**: escolha o lote (protocolo + data) que deseja acompanhar.
- **Resumo de adesão**: "X de Y colaboradores responderam", com indicador visual.
- **Acompanhamento por Colaborador**: tabela com **Colaborador** e **Status** (respondido / pendente).
- **Exportar Excel**: gera um arquivo com o relatório de adesão.

## Como usar
1. Selecione o **Lote** desejado.
2. Veja o resumo e a lista de colaboradores e seus status.
3. Clique em **Exportar Excel** para baixar o relatório.

> Dica: troque o lote para comparar a adesão entre diferentes campanhas/protocolos.

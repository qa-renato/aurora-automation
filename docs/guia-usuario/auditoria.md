# Auditoria

Tela com o **histórico de ações** realizadas no sistema (trilha de auditoria).

## O que você vê
Uma tabela com **Data e Hora, Usuário, Ação, Recurso e Decisão**, além de um campo de **busca** por usuário, ação ou recurso.

## Como usar
1. Use a **busca** para localizar ações de um usuário ou recurso específico.
2. Consulte a coluna **Decisão** para ver o resultado de cada ação registrada.

> A visualização da Auditoria depende do seu **perfil de acesso**.

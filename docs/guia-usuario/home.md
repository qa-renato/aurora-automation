# Home / Painel

A tela inicial mostra um **resumo do bem-estar da empresa** e atalhos para os relatórios.

## O que você vê
- **Índice de Bem-Estar** (escala 0–100): quanto maior, melhor o bem-estar geral.
- **Média Geral de Risco** (escala 1–5): nível médio de risco identificado.
- **Balança: Trabalho vs. Vida** (escala 1–5): equilíbrio entre trabalho e vida pessoal.
- **Casos Graves**: contador de casos que requerem atenção imediata, com o botão **Gerenciar Casos**.
- **Acordeões de relatórios**: seções que se expandem para abrir os relatórios:
  - Relatórios das Entrevistas Individuais (Ansiedade, Desesperança, Ideação Suicida, Depressão)
  - Relatório da Entrevista Ocupacional (COPSOQ)
  - Resultados Consolidados

## Como usar
1. Confira os indicadores no topo para uma leitura rápida da situação.
2. Clique em um **acordeão** para expandir e depois em **"Visualizar Dashboard"** para abrir o relatório.
3. Use **Gerenciar Casos** para ir direto à gestão dos casos graves.
